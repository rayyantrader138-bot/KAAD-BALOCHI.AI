# KAAD AI — GitHub par chalane ka tareeqa
1. GitHub par naya repo banao, in 4 files (index.html, style.css, app.js, README.md) upload karo.
2. Repo > Settings > Pages > Source: "Deploy from a branch" > main / root > Save.
3. 1-2 minute baad link milega: https://USERNAME.github.io/REPO/
4. Website kholo > 🔑 dabao > apni Gemini API key daalo (https://aistudio.google.com/apikey). Key sirf aapke browser mein save hoti hai, code mein nahi.
Mic ke liye HTTPS zaroori hai (GitHub Pages mein hota hai). Chrome best hai.
