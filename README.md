# KAAD AI (Groq version) — GitHub par chalane ka tareeqa
1. GitHub par naya repo banao, in files (index.html, style.css, app.js, README.md) upload karo.
2. Repo > Settings > Pages > Source: "Deploy from a branch" > main / root > Save.
3. Link: https://USERNAME.github.io/REPO/
4. Website kholo > 🔑 dabao > apni Groq key (gsk_...) daalo. Key sirf aapke browser mein save hoti hai.
Groq text/voice/vision karta hai; image banane ke liye free Pollinations use hota hai (URL 🔑 settings mein badal sakte ho).
Mic ke liye HTTPS zaroori hai (GitHub Pages mein hota hai). Chrome best hai.
